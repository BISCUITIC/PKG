# ReadingInformationGraphicFiles

WPF-приложение для лабораторной работы №2. Анализирует растровые файлы JPEG, GIF, TIFF, BMP, PNG и PCX.

## Важно для существующего проекта Visual Studio

Этот вариант предназначен для проекта, который уже создан шаблоном WPF. Он **не изменяет** существующие `App.xaml`, `App.xaml.cs`, `MainWindow.xaml`, `MainWindow.xaml.cs` и `.csproj`.

Патч только добавляет:

- `ImageInfo.cs`;
- `ImageMetadataReader.cs`;
- `MainWindow.Functionality.cs`;
- документацию.

SDK-style WPF-проект автоматически включает новые `.cs` файлы в сборку.

## Запуск

Откройте существующий `.sln` и запустите проект. Интерфейс лабораторной работы создаётся дополнительной частью `MainWindow` после запуска.

## Поддерживаемые форматы

`.jpg`, `.jpeg`, `.gif`, `.tif`, `.tiff`, `.bmp`, `.png`, `.pcx`.

Поля: имя файла, размер в пикселях, DPI, глубина цвета и сжатие. Дополнительно отображается формат и размер файла.

Файлы читаются по заголовкам и метаданным без полной загрузки растровых данных.
