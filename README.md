# Lab 2 — Image Information

WPF-приложение для массового чтения основной информации о растровых изображениях.

## Возможности

- выбор папки с изображениями;
- обработка JPG, GIF, TIFF, BMP, PNG и PCX;
- отображение имени файла, размера, разрешения, глубины цвета и сжатия;
- обработка большого количества файлов без блокировки интерфейса;
- отображение ошибок для отдельных файлов без остановки всего сканирования.

## Запуск

Открыть решение в Visual Studio и запустить проект `ImageInfo.Wpf`.

В интерфейсе выбрать папку и нажать **Сканировать**.

## Технологии

- C#
- .NET 8
- WPF
- `System.Drawing`
- `MetadataExtractor`
