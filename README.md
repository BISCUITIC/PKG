# Обработка цифровых изображений

Настольное приложение для обработки и анализа цифровых изображений, разработанное на C# с использованием WPF.

Проект реализует методы адаптивной пороговой обработки и сегментации изображений для обнаружения точек, линий и границ объектов.

## Возможности

- **Пороговая обработка**
  - Метод Ниблэка
  - Метод Сауволы
  - Адаптивная обработка по локальному среднему
  - Адаптивная обработка по гауссовому взвешенному среднему

- **Сегментация изображений**
  - Обнаружение изолированных точек
  - Обнаружение линий четырёх направлений
  - Выделение границ с помощью оператора Собеля

- **Работа с изображениями**
  - Загрузка изображений из файлов
  - Преобразование в полутоновое изображение
  - Просмотр и сравнение исходного изображения с результатом обработки
  - Настройка параметров алгоритмов
  - Сохранение результатов в формате PNG

## Используемые технологии

- C#
- .NET
- Windows Presentation Foundation (WPF)

## Назначение

Проект разработан в рамках лабораторной работы по дисциплине «Основы обработки цифровых изображений». Цель проекта — изучение и практическая реализация основных методов пороговой обработки и сегментации цифровых изображений.
