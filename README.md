# ColorConverter

Лабораторная работа №1 — десктопное приложение для преобразования цветовых моделей **RGB, XYZ и LAB**.

Цвет задаётся через числовые поля, ползунки или палитру Windows. Все модели пересчитываются автоматически, а выбранный цвет отображается в предпросмотре. При выходе за пределы sRGB компоненты RGB ограничиваются и выводится предупреждение.

**Технологии:** C#, .NET 9, WPF, MVVM.

**Запуск:**

- Открыть `ColorConverter.sln` в Visual Studio с поддержкой .NET 9 и запустить проект `ColorConverter`. Требуется Windows!
- Скачать архив `7z` с последней версией. Требуется Windows!
