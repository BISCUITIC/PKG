# Сопроводительная документация

## Назначение

Программа считывает основную информацию о растровых изображениях из выбранной папки. Поддерживается обработка до 100000 файлов с форматами JPG/JPEG, GIF, TIFF/TIF, BMP, PNG и PCX.

## Внешние библиотеки

Сторонние библиотеки для разбора изображений не используются. Применяются стандартные API .NET/WPF (`System.IO`, `System.Buffers.Binary`, `Microsoft.Win32`, `System.Windows`). Поэтому проект не требует NuGet-пакетов.

## Откуда берутся данные

- **JPEG**: размер и глубина берутся из SOF-сегмента; DPI — из JFIF APP0 или EXIF APP1; информация о кодировании определяется по маркерам JPEG.
- **PNG**: ширина, высота и bit depth — из IHDR; DPI — из pHYs при наличии; для PNG указывается Deflate/zlib.
- **GIF**: ширина, высота и параметры палитры — из Logical Screen Descriptor; стандартный способ сжатия изображений GIF — LZW.
- **BMP**: размеры, bits per pixel и compression — из DIB-заголовка; DPI — из полей X/Y pixels per meter.
- **TIFF**: размеры — теги 256/257, глубина — 258, сжатие — 259, разрешение — 282/283 и единица разрешения — 296.
- **PCX**: размеры и DPI — заголовок PCX, глубина — BitsPerPixel × NumberOfColorPlanes, сжатие — RLE.

## Почему это быстро

Для определения основных характеристик не требуется декодировать весь растровый массив. Программа открывает файл и читает только необходимые заголовки и блоки метаданных. Обработка нескольких файлов выполняется параллельно, а отображение результатов в DataGrid виртуализировано.

## Основные характеристики

- **Размер изображения** — ширина и высота в пикселях.
- **Разрешение** — количество пикселей на дюйм (DPI), важно для вывода изображения на печать и физического размера.
- **Глубина цвета** — число бит, используемых для хранения цвета пикселя/каналов или индекса палитры.
- **Сжатие** — алгоритм или способ кодирования данных изображения внутри формата.
